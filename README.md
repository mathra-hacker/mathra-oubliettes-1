# Mathra Oubliettes

A dungeon logic puzzle for Android by Denuwan Akash (දෙනුවන් ආකාශ්).

TikTok: https://www.tiktok.com/@mathra_quotes_1 · Contact: 0783756055

Built on the open-source game Oubliettes by all3f0r1 (GNU GPL v3, see LICENSE).

The game is available in English and Sinhala (සිංහල): use the language button on the main screen. The Sinhala texts are in `app/src/main/kotlin/app/oubliettes/Sinhala.kt` (screens) and `game/Hint.kt` (hints).
